# 3D 8-Ball Pool Game

Game simulator biliar 3D interaktif yang berjalan langsung di browser tanpa instalasi tambahan.

## 🎮 Cara Bermain

1. **Pilih Mode Bermain:**
   - **Versi Computer (VS AI):** Bermain melawan komputer dengan tingkat kesulitan yang bisa disesuaikan.
   - **Bermain Berdua (VS Player):** Mode bergantian (turn-based) pada satu perangkat.

2. **Kontrol Permainan:**
   - **Panah Kiri / Panah Kanan (`←` / `→`):** Mengatur arah dan sudut bidikan stik biliar.
   - **Tahan Tombol Spasi (`Spacebar`):** Mengisi tenaga/kekuatan pukulan (lihat indikator di sebelah kanan layar).
   - **Lepas Tombol Spasi:** Memukul bola putih.

3. **Aturan Dasar & Waktu:**
   - Setiap pemain memiliki **Waktu Giliran (30 Detik)**. Jika waktu habis, giliran akan otomatis berganti.
   - Masukkan bola warna ke dalam lubang untuk mendapatkan poin.
   - Jika bola putih masuk ke dalam lubang (Foul), bola putih akan dikembalikan ke posisi awal.

4. **Pengaturan Kesulitan AI:**
   - Kamu dapat memilih level **Mudah (Easy)**, **Sedang (Medium)**, atau **Sulit (Hard)** untuk melatih ketangkasan bermain.
